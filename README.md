<h3>Задание 7</h3>
<h5>Определение погоды по координатам</h5>
<hr>
<h3>Приложение умеет:</h3>
<ul>
      <li>Показывать местную погоду </li>
      <li>Показывать погоду в конкретном городе </li>
      <li>Сохранять и демострировать историю запросов (последние 5)</li>
      <li>Завершать работу после нажатия пользователем соответствующей кнопки</li>
</ul>

<h3>Как работает программа</h3>
<ol>
  <li>Информация о погоде по названию города будет получена с помощью <a href="https://openweathermap.org/current">API openweathermap</a> и <a href="https://openweathermap.org/api/geocoding-api">Geocoder API</a>. Благодаря библиотеке <strong>requests</strong> формируется запрос, результатом которого являются:
    <ul>
      <li>Текущее время</li>
      <li>Название города</li>
      <li>Погодные условия</li>
      <li>Текущая температура</li>
      <li>Ощущается как</li>
      <li>Скорость ветра</li>
  </ul></li>
  <li>Tекущее местоположение определяется с помощью  <a href='https://ip-api.com/docs/api:json'>IP-API</a>. API возьмет ip и выдасат название города, в котором Вы находитесь.</li>
  <li>История результатов запросов хранится в базе данных, исользование которой возможно благодаря библиотеке <strong>sqlite3</strong>. Вывод осуществляется следующим образом: cначала идет первая строка с подписями столбцов, а потом n последних запросов. Пользователю предоставляется возможность выбора количества строк истории. Вся работа с базой данных реализована через класс.</li>
    <li>Интерфейс программы будет консольным. После запуска кода в консоли появляется приветственное сообщение, в котором пронумерованы функции программы:<br>
      <img src = "https://github.com/user-attachments/assets/2a48e80b-4de0-4fca-acbf-9d9f504e593b"><br>
    Далее пользователю предлагается ввести номер пункта. Введенное значение проверяется на корректность, и в случае успеха запускается функция, соответствующая выбранному пользователем действию.</li>
  <li>После выполнения действия, в консоль выводится результат, представленный на картинке ниже, и приветственное сообщение, структура которого описана в пункте 4.<br>
    <img src="https://github.com/user-attachments/assets/9ea19a05-bcc2-4ccb-811b-5039a4fa7da0"> 
  </li>
</ol>
<h3>Как запустить проект локально</h3>
 <ol>
      <li>Создание виртуального окружения: python -m venv /path/to/my_venv </li>
      <li>Активация виртуального окружения: 
            <p>Mac/linux - source ./venv/bin/activate</p>
            <p>WIndows - .\venv\Scripts\activate.bat</p></li>
      <li>Установка зависимостей из файла <a href='https://github.com/bezalabernaya/task_7/blob/main/requirements.txt'>requirements.txt</a>
</li>
  </ol>
  ```bash
# активируйте виртуальное окружение, иначе поставите все в python, который у вас в PATH прописан.
pip install -r requirements.txt
```
